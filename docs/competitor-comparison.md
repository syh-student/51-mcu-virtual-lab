# 竞品对比：Wokwi / Tinkercad Circuits / ViDBo

> 整理日期：2026-11-27
> 对比对象：本项目（51 单片机虚拟实验台） vs. 三个同类在线/开源虚拟开发板产品
> 结论先行：三家都是「单页、单板、单工程」；本项目的差异化在**中文教学闭环 + 完全离线 + 桌面版**，不在芯片数量上。

---

## 一、四家速览

| 维度 | Wokwi | Tinkercad Circuits | ViDBo | 本项目 |
| --- | --- | --- | --- | --- |
| 支持芯片/板型 | 40+：Arduino、ESP32、STM32、Pi Pico、ATtiny 等 | 少：Arduino Uno、micro:bit、ATtiny | FPGA 板（需自接 RTL 仿真后端） | 仅 51（STC89C52RC）一种 |
| 仿真性质 | 数字仿真，覆盖较全 | 数字 + 简单模拟 | RTL 级（Verilator） | 教学级 C51 解释器 |
| 代码 IDE | Monaco 编辑器，以单工程为主 | 积木 + 文本，能力弱 | 无 | 多文件工程、断点单步、调用栈、Keil 工程导入 |
| 电路画布 | 元件连线（无原理图/PCB） | 面包板拖拽，面向零基础 | 仅一张开发板图片 | 电路实验台 + 原理图↔PCB 双视图 + DRC |
| 时序 / 逻辑分析仪 | 有（Virtual Logic Analyzer） | 无 | 无 | 有，带光标 A/B 测 Δt、可导出 PNG/CSV |
| 网络仿真 | 有，支持 MQTT / HTTP / NTP | 无 | 无 | 无 |
| 教学资源 | 英文文档与示例 | 课堂管理、教案，偏 K12 | 无 | 中文讲义 + 16 个例程 + 自测题 + 参数计算器 |
| 离线 / 隐私 | 需联网；免费版工程**强制公开** | 需联网 | 本地运行，但需自己搭环境 | 完全离线，工程存本地，不需注册 |
| 平台 | 网页 + VS Code 插件 | 网页 | 浏览器前端 + 协议 | 网页 + Windows Electron 桌面版 |
| 许可 | 闭源商业产品 | 闭源，Autodesk 所有 | 开源，Apache-2.0 | 开源，MIT |
| 价格 | 免费版 €0（仅公开项目）；Hobby €7/月；Hobby+ €12/月；Pro €25/席/月 | 全部免费 | 免费 | 免费 |

## 二、逐个看

### 1. Wokwi

**定位**：全球最知名的在线电子仿真器，主打「不用买硬件就能跑 Arduino / ESP32 / STM32 / Pico」。

**界面**：三栏式，左代码右电路下终端。

![Wokwi 界面](https://aka.doubaocdn.com/l/eHIi3bPIOz)

- 左栏：类 VS Code 的深色编辑器，顶部有 `diagram.json`（电路连线用 JSON 描述）和 Library Manager。
- 右栏：黑底仿真画布，一块开发板 + 若干外设，彩色导线连接，右上角绿色运行键和仿真耗时。
- 底部：终端，打印 `Serial.print` 的内容。

**价格与限制**（官方定价页）：

| 计划 | 价格 | 关键内容 |
| --- | --- | --- |
| Community | €0 | 无限仿真、无限**公开**项目、虚拟 WiFi；工程对所有人可见 |
| Hobby | €7/月 | 100 分钟/月快速构建、不公开项目、自定义库 |
| Hobby+ | €12/月 | 500 分钟、VS Code 插件、自定义 WiFi AP |
| Wokwi Pro | €25/席/月 | 1000 分钟构建 + 2000 分钟 CI、离线插件、团队计费 |

**优点**

- 板型与器件最全，生态最成熟，社区示例极多。
- 网络仿真（MQTT / HTTP / NTP）是独有优势，适合 IoT 教学。
- 虚拟逻辑分析仪可直接抓 UART / I2C / SPI。
- 分享一个链接就能让别人打开同一个工程。

**缺点**

- 免费版工程只能公开，学生代码等于公开；私有要付费。
- 没有原理图 / PCB 设计能力，也没有 DRC。
- 中文教学资源几乎为零，界面与文档全英文。
- 必须联网，离线只能靠付费的 VS Code 插件。

---

### 2. Tinkercad Circuits

**定位**：Autodesk 出品的免费网页工具，面向 K12 与入门课堂，把电子元件做成「电子积木」。

**界面**：白底、圆角、卡通。

![Tinkercad Circuits 界面](https://aka.doubaocdn.com/l/bqhl7GI5WM)

- 左侧浅灰画布，中间面包板 + Arduino Uno，右侧一列卡通化的元件库（电阻、LED、按钮、电池）。
- 顶部绿色 `Start Simulation`，点一下通电；`Code` 按钮可切到积木或文本编辑器。
- 底部串口监视器。

**优点**

- **完全免费**，官方原话「free for everyone, no downloads, no strings attached」，无功能墙。
- 零门槛：拖拽元件、颜色区分导线，不认引脚编号也能搭。
- 有课堂管理（班级、作业、学生作品私有），适合老师直接布置。
- 可直接把电路嵌到网页里。

**缺点**

- 仿真深度浅，板型少（基本只有 Uno / micro:bit / ATtiny）。
- 没有时序图、没有逻辑分析仪，测不了时序。
- 没有多文件工程概念，代码能力停在单文件。
- 必须联网、必须注册账号。

---

### 3. ViDBo

**定位**：开源项目，全称 *Virtual Development Board*，本质是「给仿真器配一个浏览器里的板子」的**协议**，不是成品软件。

![ViDBo 架构](https://aka.doubaocdn.com/l/VqtuVVdxBb)

- 左侧 Verilator 跑 RTL 仿真，中间 ViDBo adapter，通过 websocket 把 IO 状态推出去。
- 右侧浏览器里是一张开发板图片，LED、开关随状态变化。
- 只定义 websocket 上的协议，不管两端是什么。

**优点**

- Apache-2.0，随便改、可商用。
- 思路干净：仿真后端与界面解耦，任何语言、任何前端都能接。
- 对 FPGA / HDL 教学是低成本方案。

**缺点**

- 不是产品，是零件；没有编辑器、没有元件库、没有教学流程。
- 需要自己搭 Verilator、写 adapter，普通学生用不起来。
- 2021 年后基本停更（最后提交 2021-11），star 约 59。

---

### 4. 本项目（51 单片机虚拟实验台）

**定位**：把「写代码 → 编译 → 看现象 → 量时序」压进同一个网页的 51 单片机学习工具，纯前端、零运行时依赖、可离线、有 Windows 桌面版。

**已有能力**（据 README）

- **写代码**：C51 教学级解释器（变量、数组、函数、static、typedef、struct、SFR、宏与条件编译）；Keil 式多文件工程与链接；`.uvproj/.uvprojx` 导入；语法高亮、断点、单步、调用栈、F12 跳转。
- **开发板**：功能板（LED×8、K1~K4、4×4 矩阵键盘、数码管、LCD1602、蜂鸣器）+ 引脚板（40 脚实物排布），12 MHz、定时器 0/1、外部中断、串口。
- **时序图**：全程 / 200 ms / 1 s / 5 s 窗口，1×/4×/16× 缩放，光标 A/B 测 Δt，导出 PNG/CSV。
- **硬件实验室**：元件库、拖拽连线、撤销重做、网格吸附、画布自动保存；原理图↔PCB、网络表、DRC；参数计算器（限流、色环、分压、RC、三极管偏置、功耗）；自测练习。
- **工程与分发**：`.c51proj.json` 存档、分享链接、Service Worker 静默更新、Electron 免安装版 / 安装版。

**已知边界**（据 README「已知边界」）

- 教学级仿真，不是指令级模拟器；不生成 `.hex`，不含烧录环节。
- 不支持指针与函数指针、`union`、位域。
- 不支持 I2C / 单总线 / ADC 等协议级外设。
- 定时器模式 0、8×8 点阵、DS1302 未支持。
- 引脚板覆盖 LED、数码管、点阵、按键、矩阵键盘、蜂鸣器、LCD1602 与串口；LCD12864 未支持。

## 四、我们的优势

1. **功能闭环最完整**
   IDE、开发板、时序图、电路画布（原理图 + PCB + DRC）、计算器、测验，六块都在一个产品里。
   Wokwi 缺原理图与 PCB；Tinkercad 缺时序图与多文件工程；ViDBo 基本只有「一块板子」。

2. **中文成套教学**
   讲义 + 16 个例程 + 自测题 + 参数计算器，按国内课程顺序组织。三家都没有中文教学体系，Tinkercad 的课堂功能是英文 K12 场景。

3. **完全离线 + 本地隐私**
   不注册、不联网、工程不上传，还能装成桌面软件。
   Wokwi 免费版恰好相反——**工程强制公开**。这一点是可以直接讲给老师和学生听的差异，不是参数表上的小数点。

4. **Keil 工程可迁移**
   直接读 `.uvproj/.uvprojx`，学生可以从真工具链平滑迁过来，竞品都没有这条路。

5. **桌面版**
   三家全是网页；本项目有免安装 exe 和安装版，双击即用，适合机房、无网教室、演示场景。

---

## 五、我们的劣势

1. **只有一种芯片**
   这是最致命的。Wokwi 已经 40+ 板，本项目的「多芯片」还停在规划里，名字也没定。
   一旦用户想学 STM32 或 ESP32，只能离开。

2. **教学级内核，深度不够**
   不支持指针、函数指针、`union`、位域；不支持 I2C / 单总线 / ADC；不生成 `.hex`。
   课程做到中后期、工程一复杂就会撞墙，用户会回到 Keil。

3. **没有网络与 IoT 仿真**
   ESP32 + MQTT 这类现在最热的课堂内容做不了，而这正是 Wokwi 的护城河。

4. **没有账号、云协作、社区**
   分享靠链接，作品无法沉淀成社区；三家都有不同程度的分享与作品库。

5. **分发细节**
   安装包未签名，Windows 会出现「未知发布者」；111 MB 的免安装包对纯网页产品来说偏重。

## 六、结论与下一步

### 定位

不要和 Wokwi 正面拼「板多、仿真准、社区大」，短期拼不过。
本项目应该守住三个别人不容易复制的点：

- **国内课程闭环**：讲、练、测、算在一条线上；
- **本地优先**：离线、不注册、代码不外传；
- **桌面形态**：可安装、可分发、适合机房与无网环境。

一句话定位建议：

> 给国内单片机课堂用的、装上就能跑的虚拟实验台——不是在线玩具，是本地教具。

### 多芯片的正确起点

将来加第二种芯片，第一步不是写新芯片，而是先把现在和 51 绑死的解释器抽象出一层 **「芯片内核接口」**：

```
IDE / 开发板 / 时序图 / 电路画布
            │
      芯片内核接口（统一 API）
            │
   ┌────────┼────────┐
  51 内核   AVR 内核   STM32 内核
```

所有上层功能只依赖接口，不直接碰 51 的 SFR 名、机器周期、端口位。否则每加一颗芯片，整个 app 都要改一遍，越往后越改不动。
